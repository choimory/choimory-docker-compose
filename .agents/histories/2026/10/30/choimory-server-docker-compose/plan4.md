# 지금 내용들 public repository로 공개하도 돼?

> 지금 내용들 public repository로 공개하도 돼?

## 답변

공개해도 됨. 비밀번호, 토큰, 키 같은 실제 비밀값은 없음. 다만 정리하면 좋을 항목이 두 개 있음

## 확인 결과

- **비밀값**: 없음. `.env.example`에는 `changeme` 같은 자리표시자만 들어 있음
  - Vaultwarden `ADMIN_TOKEN`: `$argon2id$...$change-me` 형태의 예시값
  - Immich `DB_PASSWORD`: `changeme`
- **실제 `.env`**: `.gitignore`에 들어 있어 커밋되지 않음
- **Tailscale 정보**: tailnet 이름과 Tailscale IP는 `<tailnet>`, `100.x.x.x`로만 적혀 있음
- **Immich의 `sha256` digest**: 공식 이미지 해시라 공개 정보
- **`.agents/rules`의 이메일과 비밀번호**: `choi@example.com`, `Password1!` 같은 문서 예시값

## 정리하면 좋을 항목

1. **plan1의 Notion 링크 2개**
   - 페이지가 비공개면 링크가 노출되어도 로그인 없이는 볼 수 없어 위험은 낮음
   - 반대로 "웹에 게시" 상태라면 누구나 내용을 볼 수 있음. 하위 페이지에 ChatGPT, Claude 대화 링크와 서버 세팅 상세 내용이 있음
   - Notion 공유 설정을 확인하거나, 링크를 지우는 걸 권함
2. **`homepage/.env.example`의 `192.168.0.14`**
   - 사설 IP라 외부에서는 접근할 수 없어 실질적인 위험은 없음
   - 다만 예시 파일이니 `192.168.0.x`처럼 자리표시자로 바꾸는 게 깔끔함

## 참고: 서비스 구성이 공개되는 점

포트 할당표, 앱 목록, 서버 사양이 공개됨. 하지만 공유기 포트포워딩이 없고 접속을 LAN과 Tailscale로만 받는 구조라, 이 정보를 알아도 외부에서 공격할 수 있는 경로가 없음. 실질적인 위험은 낮음

## 커밋할 때 주의

나중에 서버에서 `.env`를 만든 뒤 커밋할 때는 `git status`로 `.env`가 빠져 있는지 한 번 확인

# /data 같은 디렉토리 노출되는건 어케 생각해

> ' /data 같은 디렉토리 노출되는건 어케 생각해

## 답변

걱정하지 않아도 됨. `/data` 같은 경로가 공개돼도 보안상 위험은 거의 없음

## 이유

1. **경로를 안다고 들어올 수 있는 건 아님**: 경로 정보는 공격자가 이미 서버 안에 들어왔거나, 어떤 앱의 파일 읽기 취약점을 이용할 수 있을 때만 쓸모가 있음. 지금 구조는 인터넷에서 접근할 경로가 없고, LAN과 Tailscale로만 접속을 받음
2. **이미 들어온 공격자라면 어차피 금방 알아냄**: `ls /`, `mount`, `docker inspect` 한 번이면 경로가 다 나옴. 숨겨서 얻는 보안 효과가 거의 없음
3. **흔한 경로**: `/data`, `/opt`, `/srv` 같은 경로는 홈서버에서 관례적으로 쓰는 이름이라 특별한 정보가 아님

## 실제로 신경 써야 할 것

경로를 숨기는 것보다 다음이 훨씬 중요함

- **외부 노출 차단 유지**: 공유기 포트포워딩을 열지 않고, Cloudflare Tunnel로 개인 앱을 공개하지 않기
- **Tailscale 계정 보안**: Tailscale 계정에 들어오면 tailnet 전체에 접근할 수 있으므로 2단계 인증 켜기
- **Dockge 보호**: Docker 소켓을 쥐고 있어 사실상 root 권한. 강한 비밀번호를 쓰고, 지금처럼 `127.0.0.1` + `tailscale serve`로만 열기
- **이미지 업데이트**: 태그를 고정해 두었으니 주기적으로 버전을 올려 보안 패치 반영

## 숨기려면 드는 비용

경로를 `.env`의 `DATA_ROOT` 같은 변수로 빼면 숨길 수는 있음. 하지만 이 저장소에서 경로 구조는 설정의 핵심이라, 숨기면 compose 파일만 보고 구조를 이해하기 어려워짐. 얻는 보안 효과에 비해 손해가 커서 지금 그대로 두는 걸 추천

정리하면 공개해도 괜찮음. Notion 링크와 `192.168.0.14` 두 항목만 정리할지 결정 필요
